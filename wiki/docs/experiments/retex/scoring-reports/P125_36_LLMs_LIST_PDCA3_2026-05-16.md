## Note critique sur le panel

**Tous les 36 modeles sont open-weight, testes via Cloudflare Workers AI en octobre 2024** (Section 3.1, p.5).
- Aucun modele closed-source (GPT-4, Claude, Gemini, etc.) dans le panel
- Range parametres : **0.5B a 14B** (pas de gros modeles)
- Quantizations diverses : FP16, FP8, INT8, AWQ, LoRA

**Implication pour le claim "strong correlation parameters/vulnerability"** :
Cette correlation est etablie sur un range limite (0.5B-14B). L'extrapolation a 70B+ (LLaMA 3.3 70B, Claude Sonnet, GPT-4) **n'est pas justifiee par les donnees du paper**. Ceci est une limitation methodologique a noter dans le Chapitre IV.

## Implication budget reproduction G-007

**Budget initialement estime** : $300-800 (mix closed/open)
**Budget revise (PDCA-3)** : **~$0-50** car panel 100% open-weight
- Ollama local pour les 30+ modeles 7B et moins
- Groq API gratuit pour LLaMA 3.x family
- HuggingFace local pour quantizations rares (LoRA, INT8)
- Replicate ~$5/modele x 5 modeles less common = ~$25

**Conclusion** : G-007 reproduction est **quasi gratuite**. Probleme reel = **temps GPU**, pas budget API.
